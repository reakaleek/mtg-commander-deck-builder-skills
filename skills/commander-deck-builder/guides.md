# Deckbuilding questions

Answer each item from this commander, this list, and this interview. Do not bring stored targets. Do not name cards here.

## Categories

Count lands, ramp, card advantage, targeted interaction, mass interaction, and plan cards.

Give each card one primary role for the totals. Optional secondary tags are fine for analysis.

Ask whether this commander already supplies a category. If it does, count that supply when you judge the list.

Report the raw counts. No target column.

Judge enough or not enough from curve, colors, table rules, and how the commander plays.

## Mana base

Does land count and fixing match pip pressure from Scryfall `mana_cost` and `produced_mana`, color count, ramp density, and budget if any?

If a budget exists, prefer cheaper fixing that still makes the colors.

Keep basics in play when the manabase needs them.

## Win conditions

How does this list actually close a game?

Do those lines survive the table rules they stated?

Tutors count only if the pieces they find are present in the deck.

"Good cards" is not a win condition.

## Curve

Do mana values match how fast this commander wants to play?

Explain clumps. Do not enforce a peak mana value.

## Brackets and Game Changers
