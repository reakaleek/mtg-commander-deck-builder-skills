# Deckbuilding questions

Answer each item from this commander, this list, and this interview. Do not bring stored targets. Do not name cards here.

## Categories

Count lands, ramp, card advantage, targeted interaction, mass interaction, and plan cards.

Give each card one primary role for the totals. Optional secondary tags are fine for analysis.

Ask whether this commander already supplies a category and when it normally
starts supplying it. Count that supply when you judge the list, but do not
call a late commander early ramp or draw. Also distinguish cards that work
alone from cards that need another permanent, a graveyard, or a token.

Count always-tapped lands and other mana sources that enter play delayed.
When a card checks a property of other cards, check that property across the
whole list (including unique names, land types, creature types, snow, historic,
or modified), not only the number of lands or creatures.

Report the raw counts. No target column.

Judge enough or not enough from curve, colors, table rules, and how the commander plays.

## Mana base

Does land count and fixing match pip pressure from Scryfall `mana_cost` and `produced_mana`, color count, ramp density, and budget if any?

If a budget exists, prefer cheaper fixing that still makes the colors.

Keep basics in play when the manabase needs them.

## Win conditions

How does this list actually close a game?

Do those lines survive the table rules they stated?

Tutors count only if the pieces they find are present in the deck.

"Good cards" is not a win condition.

For every proposed add, verify that it fixes the stated failure or advances the
thesis, compare it with cards already doing that job, and say why adding it is
better than keeping the current card or making no change. If the job already
has three or more functional copies, skip the add or identify the weaker copy
it replaces. Flag dependencies and extra decisions such as optional costs,
modes, delayed triggers, or loops.

## Curve

Do mana values match how fast this commander wants to play?

Explain clumps. Do not enforce a peak mana value.

## Brackets and Game Changers

Honor the user's stated power or bracket.

Flag Scryfall `game_changer` extras against their cap.

Do not add a hidden power target.

If a card is cut, name the capability that leaves with it. Match interaction
to the requested job: stopping an attack, removing one threat, resetting one
player, or resetting the table. If the color identity cannot do that job
cheaply, say so and offer the nearest real option rather than mislabeling a
different effect.
